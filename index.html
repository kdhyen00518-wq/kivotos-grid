    키보토스 그리드 안내

    1. students_grid.json 자동 연동: 같은 폴더에 students_grid.json을 두고 웹 서버(GitHub Pages, Live Server 등)에서 열면 자동으로 전체 학생을 불러옵니다. file:// 환경에서는 내장 데이터셋으로 동작하며, 상단 버튼이나 드래그 앤 드롭으로 로컬 JSON을 즉시 적용할 수 있습니다.

    2. 3×3 이분 매칭 보장 & 이격 중복 금지: 모든 보드는 Kuhn 이분 매칭 알고리즘으로 9칸 중복 없는 해답이 100% 보장됩니다. 같은 인물(baseName)의 이격은 한 보드에 중복 배치할 수 없으며, 호시노(무장)은 방어형(10098)·공격형(10099)으로 자동 구분됩니다.

    3. 희귀도 점수 (낮을수록 고수): 라플라스 스무딩 (k + α) / (N + α·M) × 100 기반으로 마이너한 정답을 맞힐수록 낮은 점수를 받습니다. 오답·빈칸은 100점입니다.

    4. 별명·초성·조합 중 검색: 수시노, 임시노, 쿠로코, 교네루, 레후미, ㅅㅅㄴ, 호시ㄴ처럼 입력 도중에도 즉시 검색됩니다.

    5. Supabase 실시간 통계: 코드 상단 SUPABASE_CONFIG에 프로젝트 URL과 anon 키를 입력하면 실시간 LIVE STATS로 자동 전환됩니다.
